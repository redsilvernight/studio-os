# Version 0.8.3

Une version corrective : la synchronisation et les réglages du poste refonctionnent dans Studi'OS Desktop.

## Corrections

- Espaces de travail et Configuration › Intégrations IA s'affichent de nouveau : ils indiquaient à tort « Cette fonction n'est disponible que dans Studi'OS Desktop ». Les réglages de lancement de tâches à distance redeviennent accessibles.
- La synchronisation ne reste plus bloquée sur « Chargement des versions à comparer… » : sans réponse au bout de 30 secondes, un message s'affiche avec un bouton Réessayer.
- Activer ou désactiver la synchronisation automatique fonctionne de nouveau.
- Les sélecteurs de poste n'affichent plus la machine du dashboard.

## Changements

- « Synchronisation des skills » devient « Synchronisation de la Library », puisqu'elle synchronise aussi les rules et les agents.
