# Version 0.13.0

Une version qui termine le suivi des projets par leur dépôt Git : le poste retrouve vos dépôts tout seul et l'assistant de configuration est réduit à l'essentiel.

## Nouveautés

- Le serveur MCP retrouve le projet depuis les dossiers ouverts par votre outil ou le dossier courant, sans réglage manuel.
- Les dépôts détectés sur le poste mais pas encore suivis apparaissent dans Workspaces, prêts à être rattachés.
- L'assistant de configuration est réduit aux étapes propres au poste.
- Le suivi par dépôt couvre les membres, les non-membres et les forks.

## Corrections

- Un ancien démon n'empêche plus d'afficher la liste des dépôts détectés (affichage dégradé).
- Course au rattachement MCP corrigée.

## Notes de mise à jour

- Le client envoie désormais des URL de dépôt à `resolve-repository` : mettre à jour studio-client en même temps que le serveur.
