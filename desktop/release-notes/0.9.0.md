# Version 0.9.0

Une version de mise à niveau : les lancements à distance gagnent en sécurité, en réglages et en visibilité, et l'identité de vos agents devient durable.

## Nouveautés

- Réglages de lancement de machine à distance disponibles même sans espace de travail ouvert, avec un aperçu qui montre exactement les hooks appliqués, l'isolation MCP et les variables d'environnement du lancement.
- Profils de référence sélectionnables au lancement d'une tâche : un profil coche d'un coup les réglages qui vont ensemble.
- Identités d'agent durables : un assistant retrouve son identité de session en session, et la réconciliation est réversible quand le modèle change.
- Les lancements à distance expirent au bout de 2 heures, se prolongent automatiquement tant qu'il y a de l'activité, et s'arrêtent proprement à la demande. L'accès aux machines de production exige l'approbation explicite d'un humain.
- Library : sélection explicite des dépendances, aperçu des mises à jour épinglées avant installation, et la synchronisation couvre désormais aussi les skills personnels.

## Corrections

- Le CLI Codex livré avec l'application Codex est de nouveau détecté automatiquement.
- Le plugin Studi'OS fonctionne avec l'API V2 d'OpenCode ; l'isolation MCP locale est restaurée.
- Journalisation des mises à jour de configuration, restauration sans écraser vos éditions, et diagnostic des prérequis Git locaux au premier lancement.
- Labels et messages d'erreur plus clairs dans la Library (rate limit, échec d'aperçu).
