# Version 0.9.1

Une version corrective qui rend enfin visible la consommation des tâches exécutées hors des lancements : chaque session d'agent ouverte depuis son application (Claude, Codex, OpenCode) alimente désormais la fiche de la tâche.

## Nouveautés

- Les tâches exécutées manuellement depuis l'application d'un agent affichent leur consommation : durée, jetons et coût estimé en euros, dans la fiche tâche comme dans la vue projet.
- Le rattachement est automatique et vaut pour les trois outils : la session dit elle-même sur quelle tâche elle travaillait, et une session sans tâche déclarée apparaît « Sans tâche » dans son projet.
- Le coût est une estimation calculée par un tarif daté ; un modèle non tarifé reste affiché « inconnu » plutôt que d'inventer un montant. La grille peut être précisée sans mise à jour.

## Corrections

- Les tâches exécutées hors lancement n'affichent plus « Aucune mesure de consommation » alors que l'agent a bien travaillé.
- Rien ne change pour les lancements Mission Control : leur consommation reste mesurée comme avant.
