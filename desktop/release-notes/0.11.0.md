# Version 0.11.0

Une version qui rend la bibliothèque synchronisée de bout en bout : tous les skills, règles et agents sont générés depuis elle pour Claude Code, Codex et OpenCode.

## Nouveautés

- Tous les skills de la bibliothèque sont installés dans les trois outils, avec leurs fichiers de référence.
- Les mises à jour de la bibliothèque sont détectées automatiquement et attendent votre confirmation avant d'être écrites.
- Vos propres versions (overrides) restent à vous : le commun mis à jour n'est jamais appliqué à votre place.
- Le dossier Studio de la bibliothèque est réservé aux administrateurs.
- Les hooks personnels (démarrage de session, garde Git, vérification de fin) se publient au niveau utilisateur.

## Corrections

- La fenêtre « Quoi de neuf » ne revient plus à chaque ouverture une fois vue.
- Aucun fichier local non géré n'est écrasé sans confirmation, et AGENTS.md garde un bloc stable.
- La synchronisation traite les versions par lots et affiche clairement une limite de débit.
- Une override dépréciée ne masque plus la version commune.

## Notes de mise à jour

- Une migration de base de données est appliquée au déploiement (nouvelle colonne `derived_from` sur les versions).
