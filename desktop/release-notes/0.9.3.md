# Version 0.9.3

Une version de correction qui rend la page Agents plus lisible.

## Nouveautés

- Les agents inactifs sont rangés par projet, dans des cartes que l'on déplie ou replie.
- Sur la fiche d'un agent, le travail réalisé et les sessions s'affichent par pages de dix : les plus anciennes se déplient à la demande.

## Corrections

- Les longs résumés de travail sont raccourcis ; le texte complet et les preuves techniques se déplient au clic au lieu d'envahir l'écran.
