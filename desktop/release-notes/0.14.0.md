# Version 0.14.0

Une version côté serveur qui prépare l'ouverture à d'autres équipes : Studi'OS mesure maintenant ce que coûte son hébergement.

## Nouveautés

- Le serveur relève toutes les 15 minutes la taille de ses données, l'espace utilisé par projet, le nombre de connexions en direct, la mémoire utilisée et le volume des sauvegardes. Aucune de ces mesures ne contient de contenu : seulement des tailles et des nombres.

## Notes de mise à jour

- Une migration de base de données (0045) ajoute la table des mesures ; elle s'applique toute seule au déploiement.
- Le dossier des sauvegardes (`/home/ubuntu/studio-backups`) est monté en lecture seule dans le serveur ; `STUDIO_BACKUP_HOST_DIR` permet de le changer.
