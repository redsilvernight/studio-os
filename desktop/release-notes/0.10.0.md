# Version 0.10.0

Une version qui refond la bibliothèque : ressources plus claires, installables sur Claude Code, Codex et OpenCode.

## Nouveautés

- La bibliothèque est reconstruite à partir de paquets vérifiés : Studio, projet et personnel.
- Les skills peuvent contenir plusieurs fichiers, conservés tels quels à l'installation.
- Les sauvegardes et restaurations de skills préservent les fichiers locaux non gérés.

## Corrections

- Les empreintes des paquets ne dépendent plus du système d'exploitation.
