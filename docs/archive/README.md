# Archives documentaires

Ces documents conservent des audits, décisions de conception et preuves de
chantiers passés. Leurs statuts, branches et résultats de tests sont historiques.
Ils ne décrivent pas l'état opérationnel courant et ne servent pas de guide
d'installation.

La documentation maintenue part de
[l'index canonique](../Studio_OS_Documentation_Pack/studio_os_docs/00_README.md).
L'état courant du travail est porté par Studio OS.

Les rapports d'intégration Desktop Wave 1, Wave 1B et Wave 2 ainsi que l'audit
DU0 ont été rangés ici lors du nettoyage du 29 octobre 2026. Les anciens manuels
compilés PDF/Word ont été retirés au profit du Markdown ; leur historique reste
accessible dans Git.
