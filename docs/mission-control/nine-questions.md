# Mission Control — les neuf questions

Pour chaque question : où la réponse est visible, l'endpoint HTTP ou l'outil
MCP, la source de code, le test qui la couvre et sa limite honnête. Le serveur
reste la seule vérité ; une valeur absente n'est jamais remplacée par zéro ou
par une valeur inventée. « non trouvé » signale une réponse absente du
périmètre inspecté, pas une preuve universelle d'absence.
